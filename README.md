# Interest Simulator

## Overview
The Interest Simulator is a savings simulator application built using Streamlit. It allows users to explore the benefits of purchasing products through interest-free installment plans. By simulating potential savings based on different interest rates, users can make informed financial decisions.

## Features
- Select from various preset stores with predefined prices and payment plans.
- Input custom parameters for any product, including price, payment duration, and interest rates.
- Calculate potential savings when using interest-free payment options.
- Display results including original price, monthly payments, total savings, and effective discount percentage.

## Usage Instructions
1. Ensure you have Python and Streamlit installed on your machine.
2. Clone the repository or download the project files.
3. Navigate to the project directory in your terminal.
4. Run the application using the command:
   ```
   streamlit run interestFreeSavings.py
   ```
5. Open the provided local URL in your web browser to access the simulator.
6. Select a store or input your own product details, then adjust the parameters as needed.
7. Review the results to understand your potential savings.

## Requirements
- Python 3.x
- Streamlit
